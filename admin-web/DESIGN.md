# MIP Web 管理后台设计规范

## 视觉依据

Web 以 [Workbuddy 管理原型](https://bfd568111f4249be9902eba8e876cece.app.workbuddy.link/#messages) 的蓝色渐变侧栏、浅灰画布、白色卡片、紧凑数据密度和清晰当前位置为视觉依据。原型右侧 PRD、演示数字、字符图标和桌面侧栏在手机端的横向溢出不是实现目标。

设计目标是保持原型的结构和气质，同时让真实管理操作、权限边界、错误恢复与窄屏交互可用。所有视觉值通过 Ant Design `ConfigProvider` token、CSS 变量和 `shared/ui` 管理；页面不得重复声明品牌色、阴影、圆角或响应式断点。

## Design Token

| Token | 值 | 用途 |
| --- | --- | --- |
| `colorPrimary` | `#1769E0` | 主操作、链接、选中态 |
| `colorPrimaryHover` | `#1358C1` | 主操作悬停 |
| `colorInfoBg` | `#EDF5FF` | 蓝色弱强调 |
| `colorBgLayout` | `#F3F7FD` | 页面画布 |
| `colorBgContainer` | `#FFFFFF` | 卡片、表格、抽屉和弹窗 |
| `colorText` | `#26334D` | 主文本 |
| `colorTextSecondary` | `#72809A` | 次级信息 |
| `colorBorderSecondary` | `#E4EBF5` | 分隔线与浅边框 |
| `colorSuccess` | `#28A474` | 成功与正常 |
| `colorWarning` | `#D99A25` | 待处理与风险 |
| `colorError` | `#C35645` | 失败与危险操作 |
| `borderRadius` | `8px` | 控件 |
| `borderRadiusLG` | `12px` | 卡片、抽屉内容和弹窗 |
| `boxShadowSecondary` | `0 8px 28px rgb(44 76 121 / 10%)` | 浮层 |

侧栏使用 `linear-gradient(180deg, #347CE9 0%, #235BCF 55%, #1D4EB8 100%)`。页面只能使用 `var(--mip-*)` 或 Ant token 引用这些值。

## 字体层级

字体栈：`Inter, PingFang SC, Hiragino Sans GB, Microsoft YaHei, sans-serif`。

- 页面标题：24px / 32px / 650。
- 区块标题：16px / 24px / 600。
- 卡片指标：28–30px / 36px / 650。
- 正文与表格：14px / 22px / 400。
- 辅助信息：12px / 18px / 400。
- 手机页面标题：21px；正文不小于 13px。

标题只用行业通用名称，例如“网站概览”“用户管理”“订单管理”。不写口号、疑问句、营销腔或内部实现说明。

## 间距、圆角和阴影

- 间距基数 4px；常用间距 8 / 12 / 16 / 20 / 24 / 28 / 32。
- 桌面内容边距 28px，最大内容宽度 1600px；手机边距 14px。
- 卡片圆角 12px，控件 8px，状态标签胶囊圆角。
- 卡片只使用 1px 浅边框和低强度阴影；不使用大面积高饱和投影。
- 同一层级页面头、筛选栏、表格和分页的垂直节奏一致。

## 桌面布局

- 侧栏固定宽 184px，包含品牌、分组导航、可展开子项和账号区。
- 顶栏高 64px，显示当前位置、消息入口、连接状态和账号菜单。
- 页面标题区同时承载说明与当前页主操作。
- 概览使用四列指标；内容区可用 2:1 或 3:2 栅格。
- 1280px 下表格允许容器内水平滚动，但文档根节点不得横向溢出。

## 手机断点

断点统一为 `767px`。手机端：

- 桌面侧栏关闭，改为顶部栏 + 抽屉导航；抽屉不参与页面宽度。
- 页面操作折叠为主要按钮和“更多操作”，不会因隐藏而不可达。
- 指标卡单列或两列；筛选控件纵向排列；表格保留容器内滚动。
- 抽屉全屏，弹窗宽度不超过 `calc(100vw - 28px)`，底部操作固定且尊重安全区。
- 390×844 下 `documentElement.scrollWidth <= innerWidth + 1`。

## 公共界面规则

### 表格

- 使用 `DataTable` 包装 Ant Design Table。
- 表头浅灰、正文白底、行悬停浅蓝；列定义来自 module read model。
- 操作列固定在右侧，危险操作不能成为默认主按钮。
- 窄屏允许表格容器滚动；关键身份列优先固定，不能把一行拆成不完整卡片。

### 筛选栏

- `FilterBar` 写入 Router URL search，不在组件内部保存第二份筛选事实。
- 搜索、状态和分页变化重置 cursor；清除按钮恢复路由默认值。
- 服务端不支持的组合筛选不得在浏览器拼出业务结论。

### 表单

- 标签在控件上方；必填、帮助、错误、禁用理由明确。
- mutation 输入由既有 module definition、validator 和 builder 产生。
- 关闭失败弹窗不清空用户已填写内容；冲突后刷新服务端事实。

### 抽屉和弹窗

- 查看使用 `DetailDrawer`；短确认用 `ConfirmDialog`；结构化写操作用 `MutationDialog`。
- 桌面详情抽屉宽 720–860px；手机全屏。
- 标题、资源标识、版本和状态位于固定头部；动作按 capability 过滤。

### 状态标签

- `StatusTag` 同时使用文字与颜色。成功绿、待处理金、失败红、终态灰、信息蓝。
- 未知服务端状态显示原始安全文本或“未知状态”，不得推断业务含义。

### Loading、Error、Empty、Forbidden

- 首次加载使用稳定骨架；刷新保留现有内容并显示低干扰进度。
- 错误状态显示可执行的重试或登录操作，真实错误不回退 demo。
- 空状态只说明事实与可用操作，不把权限不足伪装成空数据。
- 无权限不公开缺少的敏感角色，只说明当前账号不能访问。

## 可访问性

- 所有图标按钮必须有可见或辅助标签；不使用 emoji 或字符代替图标。
- 键盘可以到达导航、筛选、表格操作、弹窗和抽屉；焦点圈至少 2px。
- 文本与背景按 WCAG AA 对比度设计；状态不只依赖颜色。
- 表格有可访问名称，表单标签与错误关联，异步状态使用合适的 live region。
- `prefers-reduced-motion` 下关闭非必要动效。

## 禁止逐页硬编码

- 页面不得声明品牌色、侧栏宽度、全局阴影、状态颜色或断点。
- 同类表格、筛选栏、详情、确认、加载和错误必须使用公共 UI。
- 页面不得复制 module formatter、action 名称、capability 或输入校验。
