# M08 新建模块与P2体验优化

> 来源: [admin-web-prd-refactor-spec.md](../admin-web-prd-refactor-spec.md)
> 模块: M08
> Wave: 1（全部 FR 互相独立，优先级较低）
> FR 覆盖: FR-027, FR-028, FR-030, FR-031, FR-032, FR-033, FR-034, FR-035, FR-036
> 内部依赖链: 无
> 预估复杂度: 中

## 定位

本模块汇集所有新建管理模块与 P2 体验优化需求。各 FR 之间无依赖关系，可独立开发。因优先级为 P1/P2，建议在 P0 核心模块（M01–M07）完成后再启动，避免分散早期精力。

## 依赖与前置

- 无跨模块依赖。
- 复用现有共享基础设施：`OperationField` / `MutationDialog` / `IndependentFormPage` / `AdminApiClient`。
- 复用 M01 列表筛选增强的时间组件与多维度筛选（M08 列表页在 M01 完成后接入筛选）。
- 涉及新数据模型或字段扩展的 FR 必须追加数据库迁移脚本（`database/mysql/migrations/`），不得直接修改现有表结构。

## FR-027: 视频回顾模块

**描述**: 新建视频回顾管理模块，支持视频内容的增删改查与上下架。

**字段**:
- 视频封面（图片）
- 视频跳转地址
- 标题
- 状态（启用 / 停用）

**功能**:
- 支持新增 / 查看 / 编辑 / 启用 / 停用
- 下架后保留历史配置和操作记录，不在小程序展示

**验收标准**:
- [ ] 字段：视频封面 / 视频跳转地址 / 标题 / 状态（启用 / 停用）
- [ ] 支持新增 / 查看 / 编辑 / 启用 / 停用
- [ ] 未上传封面时提示"请上传视频封面"
- [ ] 跳转地址为空或无效时提示"请输入有效的视频跳转地址"
- [ ] 校验失败时不可保存或启用
- [ ] 下架后保留历史配置和操作记录，不在小程序展示

## FR-033: 后台消息触发场景配置

**描述**: 消息模板按触发场景分类配置。

**触发场景分类**:
- **活动**: 报名成功 / 支付结果 / 开始提醒 / 签到成功 / 反馈提醒 / 收到邀请 / 双向心动
- **机会**: 发布成功 / 被引荐 / 收到合作申请 / 状态变化 / 合作达成
- **任务**: 收到任务 / 即将到期 / 被退回 / 验收通过 / 经验值到账
- **成长**: 经验值到账 / 用户升级 / 勋章获得
- **会员**: 权益即将到期 / 权益已到期 / 续费成功

**功能**:
- 每种场景配置消息模板 / 变量 / 跳转页面 / 启停状态
- 发送时校验变量是否完整
- 已发送消息保存实际标题 / 正文 / 变量值 / 跳转目标快照
- 修改模板不影响历史发送记录

**验收标准**:
- [ ] 触发场景：活动（报名成功 / 支付结果 / 开始提醒 / 签到成功 / 反馈提醒 / 收到邀请 / 双向心动）、机会（发布成功 / 被引荐 / 收到合作申请 / 状态变化 / 合作达成）、任务（收到任务 / 即将到期 / 被退回 / 验收通过 / 经验值到账）、成长（经验值到账 / 用户升级 / 勋章获得）、会员（权益即将到期 / 权益已到期 / 续费成功）
- [ ] 每种场景配置消息模板 / 变量 / 跳转页面 / 启停状态
- [ ] 发送时校验变量是否完整
- [ ] 已发送消息保存实际标题 / 正文 / 变量值 / 跳转目标快照
- [ ] 修改模板不影响历史发送记录
  - [x] 消息发送失败支持手动重试（单条，不支持批量自动重试）

## FR-036: 订单退款记录

**描述**: 新建活动退款记录列表。`refunds.submit` 已有退款提交，需补充退款记录查询。

**字段**:
- 退款单号
- 原订单号
- 退款金额
- 退款状态（退款中 / 退款成功 / 退款失败）
- 申请时间
- 完成时间
- 失败原因

**业务规则**:
- 仅记录活动开始前由用户发起的退款
- 会费订单不支持退款，发起会费退款时提示"会费订单不支持退款"
- 活动开始后不允许退款，提示"活动已开始，暂支持退款"

**验收标准**:
- [ ] 字段：退款单号 / 原订单号 / 退款金额 / 退款状态（退款中 / 退款成功 / 退款失败）/ 申请时间 / 完成时间 / 失败原因
- [ ] 仅记录活动开始前由用户发起的退款
- [ ] 会费订单不支持退款，发起会费退款时提示"会费订单不支持退款"
- [ ] 活动开始后不允许退款，提示"活动已开始，暂支持退款"
