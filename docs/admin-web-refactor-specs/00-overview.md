## 跨模块约定

### 共享依赖

- **M01（列表筛选增强）** 是全局基础：所有模块的列表页都消费方案 B 时间组件、多维度筛选和统一分页。M01 应最先完成或与其他模块同步开发，其他模块的列表页在 M01 完成后接入筛选。
- **OperationField / MutationDialog / IndependentFormPage** 是现有共享表单基础设施，所有模块复用，不重复造。
- **AdminApiClient / action-based RPC** 架构不变，新模块按现有模式新增 action。

### 数据库迁移

每个涉及新数据模型或字段扩展的模块，必须追加数据库迁移脚本（`database/mysql/migrations/`），不得直接修改现有表结构。

### 契约包扩展

新增 action 需同步更新 `packages/admin-contracts` 的类型定义和 action 清单。每个模块 spec 中列出了需要新增的 action。

### 验收门禁

每个模块完成后必须通过：
```bash
pnpm admin:web:verify   # 类型检查 + 契约测试 + 组件测试 + 构建 + 响应式验证
```
涉及服务端契约变更的模块还需通过 `pnpm verify`。
