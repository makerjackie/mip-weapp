# 小程序管理端优先，管理契约保持渠道中立

状态：部分被 [ADR 0004](0004-independent-web-admin.md) 取代。

MIP 当前运营人员可以统一使用 Windows 或 Mac 微信，因此先把现有小程序管理分包建设为手机和电脑双端自适应的正式运营产品，独立网页 UI 暂缓；`mip-admin-api` 的外部 interface 同时保持渠道中立，内部按用户、活动、订单、权限、消息和知识库等深模块组织，使未来增加 Web principal 与 HTTPS adapter 时无需复制业务规则、权限、审计和状态机。

保留的决定是小程序管理分包继续存在、管理契约保持渠道中立；“独立网页 UI 暂缓”不再适用。
