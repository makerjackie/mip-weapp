# ADR 0007：可选的后台手机号密码登录

状态：已接受。补充 ADR 0006；本决策不表示线上部署和账号配置已完成。

## 决策

管理后台增加手机号与密码登录，保留小程序确认网页登录。密码为可选凭据，不引入短信服务，不改变会员、管理员角色或管理范围。没有设置密码的管理员仍可以用小程序登录。

密码绑定到现有可信小程序身份和服务端已经验证的手机号。首次设置及忘记密码后的恢复，要求近期的小程序确认；密码会话修改密码时校验当前密码。客户端不得通过填写手机号、用户 ID 或角色给自己创建管理权限。

复用现有 Cloudflare BFF 会话与 D1 登录存储。密码只保存随机盐和慢哈希，既有 CloudBase 服务端负责重新确认当前身份、手机号和角色。业务请求继续执行原 capability、scope、版本及幂等校验。密码登录不接入另一套独立的 CloudBase Auth 用户目录。

## 边界

- 手机号索引使用服务端 HMAC，原始密码不进入日志、审计、源码、浏览器持久存储或验收产物。
- 未知账号、错误密码和停用账号不暴露账号是否存在；账号与来源限流失败时关闭密码登录。
- 密码变更撤销旧密码会话；退出登录撤销当前会话。小程序登录仍作为恢复入口。
- 自动化测试使用被明确授权的账号和目标环境；登录成功不授权向生产发送消息、支付或修改真实用户权限。
- 提供密码属于配置授权，不属于扩大该账号角色的授权。初始化必须匹配唯一、有效、非演示的现有用户，并核对已有运营权限。

## 对先前决策的影响

ADR 0006 中“不新增手机号密码”由本决策替代。其小程序 challenge 的单次消费、浏览器绑定和服务端确认规则保持有效。短信验证码不是本轮依赖；无需为此购买短信套餐。
