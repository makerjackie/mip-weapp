## 一、项目概述

MIP 是一款以"线下活动 + 会员体系 + 牛人合作 + 游戏化"为核心的微信小程序，配合独立 Web 后台进行运营管理。v1.1.0 在既有功能基础上：

1. 补全小程序端核心业务闭环（活动全链路、机会广场、个人中心、会员等级、勋章、订单、NPC 任务）；
2. 将原嵌于小程序内的管理功能抽离为独立 Web 后台，并新增权限、机会、任务、消息、团队等管理模块；
3. 新增游戏化系统（团队 PK、赛季排位、排行榜、队伍大本营）。

## 三、范围说明

- 上述清单共约 81 条功能点（不含游戏化模块已明确的设计/规则待补充项的细分）。
- v1.1.0 在 v1.0 已有代码基础上推进，既有活动链路、个人中心基础设施、等级勋章等业务逻辑可留用；机会、影响力、AI 助手需修复后开放；游戏化系统与独立 Web 后台为全新开发。

## 四、关键风险

1. **游戏化模块规则与设计资源未到位**：PK / 排行榜 / 队伍大本营目前无设计稿与规则文档，需产品方提供示意图与规则说明。这是工期最大不确定项。
2. **后台 PRD 待确认事项**：经验值奖励行为、等级门槛重算、权益校验、黑白名单范围、用户档案编辑、活动补录/退款、机会流水、任务重复完成、附件规格、Banner 规格、会员规则等，需产品方在第 1 周内书面答复，否则对应模块工期顺延。

## 六、双系统测试与验收

### 测试范围

微信小程序在 iOS（WKWebView）和 Android（XWeb）渲染引擎不同，常见差异包括 CSS 布局、键盘弹起、支付授权回调、长列表性能等。每个交付节点前需完成 iOS + Android 双系统真机验证，提供双系统测试报告。

### 验收标准

- 主系统（iOS）必须通过：所有 P0/P1 清零，P2 记录后续修复
- 副系统（Android）：P0/P1 须修复但不阻塞里程碑确认（修复计入下一迭代周期）
- 节点验收 = 主系统通过 + 副系统无 P0
