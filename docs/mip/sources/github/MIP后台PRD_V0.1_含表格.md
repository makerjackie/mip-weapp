# MIP 小程序后台管理系统 PRD｜报价评估版 V0.1



作者：MIP 产品团队版本：V0.1（需求范围修订）日期：2026-08-10状态：待报价评审范围：后台管理系统、后端接口及业务数据

**文档定位：**本文件用于开发方理解建设范围并评估报价，不是研发终稿。当前版本只建设用户成长、用户、活动与订单、机会、任务卡与流水、Banner 和财务七组核心能力；未列入的功能不纳入本次报价。

## 项目目标与范围

**建设目标**提供一套轻量、清晰的运营后台，完成用户成长、用户资料、活动、机会、任务、Banner 和收费数据的日常管理。

**主要用户**超级管理员、运营人员、活动运营和财务人员。

**本次范围**后台 Web、后端业务接口、数据库、基础权限、查询导出以及必要的微信支付数据对接。

**建设原则**以基础增删改查和数据查看为主，不建设复杂审批、自动化运营或规则引擎。

### 明确不在本次范围

- 游戏币、勋章、PK 赛季、排行榜、合作卡模板、微信订阅消息。
- 活动审批、机会审批及多级审核流程。
- 复杂财务对账、发票、分账、结算审批和会计系统集成。
- 小程序前台重做、详细 UI 设计、历史数据迁移及长期运维。

## 系统结构与核心流程

后台负责配置、维护和查询；小程序负责用户参与、发布和支付；产生的数据回流到后台形成运营流水。

后台配置等级/权益/任务/Banner→小程序展示与用户操作→活动报名、机会发布、任务完成、支付→业务与经验值流水→后台查询、编辑和导出



**表（sheet-id: `oZNhE7`）**

| 层级 | 组成 | 职责 |
| --- | --- | --- |
| 后台管理端 | 用户成长、用户、业务、运营、财务、系统设置 | 配置规则和内容，维护业务对象，查看流水、参与者及收费明细。 |
| 后端服务 | 用户、经验值、活动、订单、机会、任务、内容服务 | 提供数据存储、业务接口、权限校验、经验值发放和支付状态同步。 |
| 小程序端 | 现有 MIP 小程序 | 消费后台配置并产生报名、支付、任务完成、机会发布等数据；前台改造不纳入本次报价。 |

## 报价边界建议

**供应商报价建议：**按用户成长、用户、活动与订单、机会、任务与流水、Banner、财务、公共权限八部分拆分报价，并分别列出后台前端、后端接口与数据库、测试、部署上线费用。用户档案编辑作为可选项单列。

- 经验值奖励行为由后端写死，报价中不应包含可视化规则引擎。
- 活动和机会均为基础增删改查，不包含审批工作流。
- 财务模块是业务收费明细与汇总，不包含专业会计、发票、分账和复杂对账。
- 不包含游戏币、勋章、PK/排行榜、微信订阅消息及 AI 内容生成。
- 第三方账号、云资源、短信/支付通道费及对象存储费由供应商单列或由甲方承担。

## 待确认事项

1. 经验值奖励的具体行为、每项经验值、每日上限和重复行为去重方式。
2. 调整等级门槛后，已有用户是否立即按新门槛重新计算等级。
3. 等级权益仅用于前台展示，还是需要后端在实际业务中校验使用资格。
4. 黑名单限制的业务范围，以及白名单可豁免的限制范围。
5. 用户档案最终采用只读，还是购买“指定字段可编辑”的可选能力。
6. 活动是否需要后台补录/取消报名、签到和退款查看能力。
7. 机会流水具体记录发布、编辑、状态变化之外的哪些用户行为。
8. 任务是否可重复完成，用户提交后直接完成还是需要人工确认。
9. 任务附件支持的格式、数量、大小及存储周期。
10. Banner 图片尺寸和允许跳转的链接类型。
11. 会员收费对应的会员商品、购买、续费和有效期规则。
