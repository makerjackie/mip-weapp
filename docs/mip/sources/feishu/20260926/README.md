## 可直接作为后续配置来源的内容

- 行业：11 个实际一级分组、121 个二级行业，另有一行“一级=不限、二级=-”。13 个实际行业标为热门；“不限”行也标热门，保留来源但接入时映射到清除筛选，不创建名称为 `-` 的行业。
- 城市/地区：原表 375 行包含 373 个地区项及“全国”“海外”两个范围项；共 15 个热门标记。武汉、中山、香港、澳门、台湾、全国、海外均已在源表中。它们是地域标签，不能按行自动创建城市分会；“全国/海外”不能用于推断具体城市或定位坐标。
- 徽章：11 个身份成就，全部勾选“是否上线”；包括九种颜色的笨笨、城主、公会长，已有简介、永久/任期内信息。该 checkbox 表示来源意图，不证明当前产品已上线这些徽章。表中没有图片字段，发放与回收规则均为“后台配置”，不等于可自动执行的判定规则；徽章名称也不能直接转换成管理权限。
