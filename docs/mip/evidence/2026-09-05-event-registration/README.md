# 活动报名与管理修复核查

日期：2026-09-05。范围：本地工作区；包含原有并行改动，未提交、未部署、未写生产数据。本报告不把本地测试视为云端或真机验收。

## 原问题核实与修复

| 问题 | 核实与最终行为 |
| --- | --- |
| 候补晋升、管理员审核未重查资格 | 确认。重查当前账号、协议、手机号、资料以及活动要求的有效会员权益；审批活动候补转待审核，结束活动不再通过审核。 |
| 付费占位过期卡住 | 确认。原订单占位在当前窗口、资格和容量允许时续期；订单页核对当前报名关联订单后再续期、支付。未支付报名不受普通取消截止限制。 |
| 新报名表单冲突无法恢复 | 确认。刷新表单版本，保留仍兼容的已填答案，重新确认提交。 |
| 我的活动记录缺失 | 确认。保留待参加、已参加（已签到），新增历史；已结束未签到、取消、拒绝和活动关闭记录由服务端分类、计数。 |
| 拒绝手机号后的去向 | 确认代码与验收要求不符。取消待恢复意图并回到对应活动详情，保留邀请引用；真机仍待验收。 |
| 修改报名绕过门禁 | 确认。修改时重查当前参与资格和活动要求的会员权益。 |
| 编辑资料返回未刷新 | 确认。报名页重新显示时强制刷新资料摘要。 |
| 取消冲突不刷新 | 我的活动存在；详情页已有恢复。我的活动现已刷新并要求重新确认。 |
| 长表单及草稿 | 必填错误滚动定位、长选项换行；本地草稿按用户、活动、报名版本隔离，7天有效，成功提交和退出账号清除。 |
| 首次截止文案 | 确认。首次报名不再使用修改报名的截止标题。 |
| 登录预检假阳性 | 确认。所用库的登录包装不返回登录结果；改为读取官方 CLI 输出，只有明确 login:true 才通过。 |
| 安全扫描误报 | 确认。扫描具体凭证字面量和私钥内容，正常变量引用及文件路径不报泄露；回归覆盖已填凭证、空环境变量与正常引用。 |

## 补充修复

- 旧报名取消后重报，原订单迟到支付可以创建独立退款，退款提交和权威成功回调不修改新报名。
- 支付转正式名额与报名、占位续期、审核共用活动事务锁。
- 后台保存报名表时拒绝非法字段类型、重复键、无效选项和长度。
- 后台版本冲突刷新查询、保留填写内容，重新打开后使用最新版本再次确认，禁止反复提交旧版本。
- 后台只有草稿和已下架活动提供普通编辑入口，与服务端限制一致。
- 受控免费活动运行时脚本增加必填拒绝、填写、修改、持久化答案和版本回读。取消仍验证真实弹窗确认后的服务端状态；未执行时不记通过。
