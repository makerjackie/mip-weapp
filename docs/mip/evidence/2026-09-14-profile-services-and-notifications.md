# 我的服务与消息精简

日期：2026-09-14。范围：本地代码与开发者工具；未上传小程序、未部署云函数、未修改生产数据。

## 实现

- 删除全部服务、数字分身、AI 草稿、机会撮合四条用户路由及相关生产入口，同步路由、编译条件和运行时合同。已有内容与服务端历史数据保留。
- 我的页直接提供消息及未读数、团队 PK、帮助与客服、设置。主分会从顶部资料进入；关于与互动通知归入设置。
- 心动值进入统一记录：收到／发出的档案心动，及活动心动记录入口。两类事实保持独立，不重算或合并统计。
- 删除集中微信授权及签到前授权。报名结果、已报名活动详情提供自愿活动提醒；活动心动记录提供心动提醒。缺模板隐藏，拒绝不阻断业务。
- outbox 不再投影会员与内容支付成功、直接报名成功、初次提交审核／候补、本人取消、退款申请和签到成功消息；保留审核、候补晋升、运营取消、活动变更、退款完成与权益调整。签到成长事实保留。撮合结果不再产生通知。
- 历史消息保留；客户端不显示已退休目标的跳转。历史消息数量不代表新规则已经部署。
