# 会员内容后台配置验收（2026-09-26）

## 最新决定与入口

用户确认采用后台配置，允许先使用演示内容，不再等待最终资料才开发。

- Web「成长与勋章 → 会员内容配置」：等级门槛、关联权益、权益说明、现有成长事件奖励与每日上限、勋章定义、会员服务协议。
- Web「成长与勋章 → 运营操作」：沿用勋章发放/撤销和成长调整，保留授权、原因与流水。
- Web「任务管理」：沿用任务奖励配置及完成审核发放，修改配置不追溯改写已发放记录。
- 小程序「账号设置 → 会员服务协议」：读取后台保存的纯文本、版本及演示标记，提供加载、空内容、失败重试。

「填写演示示例」只预填表单，等级/权益/勋章默认为草稿；管理员可修改并启用。协议有可编辑演示正文和独立演示标记。此轮未向真实用户自动发放测试奖励，也未把本地示例写入线上。
