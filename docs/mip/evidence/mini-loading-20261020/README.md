# 小程序加载路径优化

本轮只修改客户端加载方式，不修改数据库、云函数配置、权限或资费。保留报名资格、价格、身份及订单状态的服务端裁决。

## 改动

- 身份决策返回业务事实后即可继续；头像由页面独立渐进加载。导航可复用15秒内已通过的身份快照；普通身份检查、失败重试、后台前台恢复、管理员/能力入口仍向服务器确认。退出、身份变更及过期不复用旧决策。
- 报名详情与本人报名记录并行读取；表单不再等头像、个人资料和分会标签。草稿按用户和报名版本恢复；资料迟到不能覆盖刚填写的内容，提交与幂等语义保留。
- 订单列表和详情先显示真实订单；活动/内容订单不再读会员方案。会员方案文字和封面随后加载；待支付订单先显示服务端待支付事实，再核对支付服务。旧回包不能覆盖新支付或已退出页面。
- 个人页仅加载当前栏目，超级案例和相关机会在点击时查询。设置、隐私设置、个人资料和徽章页可短时复用身份读取；显式重试与冲突恢复仍刷新服务端。
- “我的活动”封面及参与头像渐进加载。加入订单请求本机计时；不记录请求参数、个人信息或原始云日志。
- 双端排查：后台、服务端合同和数据库均无字段或行为修改；完整联合门禁验证隔离。
