## 可回退范围

数据库可通过官方 ModifyServerlessStrategy 恢复 AutoPause=yes，保留其他参数。关闭付费常驻时先将默认别名恢复到确认过的最新代码，再删除对应版本预置，防止未来发布仍留在旧数字版本。BFF 代码可用本机保留的原始 ZIP 回退；不能用回退覆盖其他有效配置、权限或网关路由。
