- 玩家等级：删除已包含压窄人物和烘焙按钮的 `hero-bg.webp`，使用需求仓库原始 `fill-1948_14084.png`（350×310）作为 `hero-character.png`，通过 `aspectFit` 保持比例。经验值入口由真实文本与点击区域呈现。
