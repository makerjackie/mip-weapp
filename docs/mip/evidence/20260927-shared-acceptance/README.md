# 测试账号与共享验收站

目标地址：<https://miptest.01mvp.com>。最终部署与 HTTPS 逐文件回读见同目录 `deployment.json`；业务函数部署单独记录，不与静态站点混为一谈。

使用 6 个既有演示账号读取测试数据库，在本机运行领域服务，并通过开发者工具复现页面。测试账号未绑定真实微信身份；本机注入角色不等于真实微信登录。

本轮延续 43 个原型步骤的左右对照，补齐非空邀请、访客、感兴趣名单和本人下架机会等数据。7 条固定隔离测试记录均已回读，签到事实为测试资料，不是扫码通过。公开图仅保留演示资料，原始数据库返回、真实账号标识、本机工具窗口和测试 transport 不公开。

## 修复

- 普通用户档案互动入口依据服务端签到事实区分锁定和隐藏；可选请求失败不让正文变成错误页。
- 人才列表按钮不再显示字面 HTML 实体。
- 邀请、访客和感兴趣名单显示公开城市、行业、身份、简介、真实服务端等级及已装备有效勋章；尊重资料可见性设置。
- QA 的 SQL 时间转换与正式 mysql2 UTC 行为对齐，消除测试截图中错误的 8 小时时差；未修改活动数据库时间。
- 验收结果将当前截图 SHA 与交互断言绑定，旧截图或不完整断言不能升级为通过。

## 验证边界

24 项实际测试数据库领域检查、3 项内存派生身份边界和 5 项接口 smoke 保留；新增页面操作只对明确列出的操作负责。退出登录已真实操作确认本机 signedOut 状态及进入登录引导页，注销仅打开和取消确认，没有注销账号。续费仅验证进入订单确认，收费报名没有下单或支付。已读回读使用仅限演示账号的原子 SQL，不代表完整生产事务链路验证。

剩余项逐页标注：真实微信登录、手机号、付款、扫码等必须真机；邀请生成仍受 QA 写入通道限制；原生解锁弹窗已观察及点击验证，但自动页面截图没有捕获原生层，不能用档案主图冒充弹窗图。资料内容、实际等级与原型示例不同属于演示数据差异，不伪造原型数字。

验收站保留下一步、上一页、批注和导出全部意见。批注仅存在各自浏览器，导出 JSON 后发回；搜索引擎禁索引不等于访问控制。站点只部署独立静态目录，不包含管理后台 Functions。

本轮未上传新的小程序体验版。正常构建与测试注入的恢复状态、全量验证和业务函数回读以同目录最终证据为准。
