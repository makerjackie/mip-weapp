## 变更

- 账号设置的注销入口改为独立确认对话框，不再在列表中展开整块表单后追加第二层确认。保留确认短语、取消关闭、提交锁和服务端账号校验；未执行真实注销。
- 活动、机会和我的复用手机号授权弹层。修复未登录身份被排除、机会页缺少组件、游客我的被全局拦截三处入口问题。显式退出过的老账号可重新登录并复用已有手机号。
- 修复授权取消、补充资料返回、登录后旧请求覆盖新身份和玩家状态刷新。用户协议仍由用户显式确认，不自动同意。
- 授权层高于自定义 TabBar，取消入口具有按钮语义及足够点击区域。
- 从原型源矢量恢复搜索图标缺失的手柄。
- 修复嘉宾 → 心动 → 查看全部参与人的返回路径：重新请求玩家列表，不再把嘉宾缓存当成玩家结果；切换失败时也不显示错误类别的旧数据。
- 新增可复用的独立 HTML 生成器：43 项左右截图、上一项/下一项、批注保存、全量 JSON 导出。截图变更后旧通过自动失效，上一轮意见只读。
