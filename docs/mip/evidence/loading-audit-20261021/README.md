# 小程序页面加载检查（2026-10-21）

本轮按用户要求检查明显的等待和跳转问题，保留必要业务校验。检查了全部 52 个注册页面的生命周期和异步调用入口：3 个主页面、44 个会员分包页面、5 个现场工作台页面。该数量是源码检查范围，不代表 52 页均已真机验收。

## 本轮修改

| 页面 | 确认的问题 | 修改后 |
| --- | --- | --- |
| 消息 | 点击后先等标记已读，再跳转；全部已读进行中不能打开消息 | 点击即开始导航，已读同步独立进行；重复点按仍受控 |
| 徽章 | 列表与可选的昵称、头像请求相互等待 | 徽章先显示，头部身份信息独立补齐 |
| 名片编辑 | 预览二维码没有返回时，整个编辑表单不能使用 | 表单先显示，二维码随后补齐，不覆盖输入 |
| 经验值明细 | 一个规则说明请求失败会让已成功的明细也整页报错 | 两个页签分别显示加载和错误状态，规则可独立重试 |
| 机会详情 | 等封面和聚合头像全部下载后才显示正文 | 正文先显示，图片独立加载 |
| 合作卡详情 | 等头像、徽章图片后才显示合作资料 | 资料先显示，图片独立加载 |
| 案例详情 | 等图片下载后才显示项目文字 | 文字先显示，图片与预览列表随后补齐 |

三个详情页补了请求顺序和离页保护。迟到图片只更新图片字段，不覆盖版本、互动结果和正文。图片渐进加载只由这些展示页显式启用，其他调用方保留原行为。

## 保留的必要流程

- 活动默认城市依赖用户主分会；不能先以全国冒充最终筛选结果。
- 报名、订单和支付需要回读服务端资格、库存、金额和账本状态。
- 编辑页的字段目录、原始资料和版本用于合法保存；没有删除这些校验。
- 现场工作台保留服务端运营权限。会员资料完备性没有替代运营授权。
- 未改变后台接口、共享契约、数据库、云函数配置或常驻数量。没有新增云资源开销。
