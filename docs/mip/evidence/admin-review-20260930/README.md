## 用户复验建议

1. 退出后马上再登录，刷新会话，确认不会闪回上一账号或上一账号的数据。
2. 在专用演示机会编辑页清空金额和全部地点，保存、刷新、重新打开，确认不会恢复旧值；需要时再填回。
3. 创建用户内容时按姓名搜索归属；打开已有内容，确认归属和类型只读，其余内容可编辑；归档内容没有编辑入口。
4. 复制一个测试活动，确认自动打开新草稿，原活动不变；新草稿的标题和时间需重新填写。
5. 桌面与手机查看概览，并切换趋势、指标分组、展开明细。
