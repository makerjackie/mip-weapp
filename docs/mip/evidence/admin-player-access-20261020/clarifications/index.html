本次已确认

  • 产品称呼：游客报名并签到至少一场活动后成为嘉宾，不限定早会；有当前有效会籍为玩家。
  • 服务端会员权限仍只有 GUEST / PLAYER；已登录游客和嘉宾均按 GUEST 检查权限。未登录是会话状态。
  • 后台角色独立授权，注册、签到或开通玩家权益不自动授予后台权限。

这覆盖旧稿“仅参加早会”和旧测试说明“登录后的非会员始终叫嘉宾”的冲突说法。外部原始资料保留原样，通过记录注明被新决定覆盖的部分。

之后按同一方式澄清

  1. 核对需求、原型、领域合同和实际代码，列出具体冲突及影响。
  2. 沿用基线问题编号，给出推荐方案并由用户确认；只暂停受影响的工作。
  3. 记录确认原话、日期、覆盖范围和剩余边界，同步需求基线、术语与验收标准。
  4. 开发和测试沿同一编号交接，另行记录实现、环境、保存回读与未验收项。
  5. 更新当前未定稿报告；定稿后冻结，后续新版本保留历史。

持续记录的仓库文件：docs/mip/REQUIREMENT_CLARIFICATIONS.md。业务规则权威仍为 docs/mip/REQUIREMENTS.md；不另外维护一套冲突需求。
