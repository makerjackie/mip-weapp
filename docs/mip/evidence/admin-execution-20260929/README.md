## 给维护者的验收入口

打开 [逐项打勾页](review.html)，其中 53 条条件直接由唯一标准生成，顺序和编号保留；可以搜索、记问题并导出反馈 JSON。当前 18 条涉及 Q-ADMIN-01～09，显示待确认；其余也不预先替人工验收打勾。按 [矩阵](../../COVERAGE_MATRIX.md#53-条场景当前记录) 查看每条还缺哪一项证明。

建议先依原编号体验：

1. **A01 + G01/G05/G06**：首次登录、等待/临时失败重试、刷新、退出后旧页。
2. **U02/U04/U07/U08**：筛选后同时打开两个用户，刷新和返回；检查完整回填、取消和仅改一个字段的保存回读。
3. **E01–E07**：活动筛选、私有草稿保存/刷新恢复/取消、复制；名单支付字段、同条件 Excel 和反馈全文。
4. **O01/O02/O04 + F01/R03**：万元/元、0/空金额、多段正文、两个对象编辑；筛选后跨页导出，核对数量与字段。
5. **A03/A05 + C01–03**：受控岗位及服务器范围、负责人/排序；素材、Banner 上限、视频封面；实际授权与发布用专门测试对象。
6. **T01–05/M01–02/X02/X03 + G07**：任务退回重提/幂等奖励、指定测试收件人的消息、知识治理；桌面和手机下检查全部操作及错误恢复。

反馈用“场景编号 + 操作步骤 + 预期/实际 + 对象名称 + 截图”，不要附密码、手机、Cookie 或含凭证的下载链接。支付/手机号、微信登录确认、扫码签到、视频号跳转仍需真机；没有用浏览器模拟它们为通过。

## 原件与脱敏

最终公共 JSON 只保留时间、计数、结果、路径/代码校验和边界；下载 XLSX、原始响应、签名 URL、账号、数据库/函数备份均留在忽略目录或维护者本机。公共入口包括[业务写入切片](runtime-readwrite.public.json)、[导出](runtime-exports.public.json)、[浏览器](runtime-browser.public.json)、[HTTPS](live-http.public.json)、[函数代码](deployed-code.public.json)、[静态文件](frontend-static.public.json)、[岗位启用](template-bindings.public.json)及[读回](template-readback.public.json)、[媒体结果](media-safety.public.json)与[对象绑定](media-binding.public.json)、[工程门禁](engineering.public.json)及[源文件快照](source-manifest.public.json)。写入切片明确保留原整轮报告曾失败的事实，后续修复在导出报告单独证明，不篡改原历史。

打勾页是本地 HTML 产物，自动浏览器打开尚未验证；安全审查拒绝 `file://`，没有转换成其他入口绕过。可由维护者手动打开该文件。它只承载原标准的人工记录，不影响当前 HTTPS 后台验收。
