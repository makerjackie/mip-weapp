## 修复与功能边界

- 角色标签采用参考稿中完整的狗策划/暴发户矢量；黑底 icon 区由 20px 改成 16px，文字起点保留距左侧 20px，恢复 icon 到文字 4px 的间隔。其他四个角色的小标签图标仍无可确认素材，不拿大型插画冒充。
- 日期入口改为参考稿网格日历，20px 控制框；文字到 icon 间距由 8px 改成 4px。整块入口可点，避免文字、图标间空隙点不到。
- 默认“近期活动”不会强行显示“今天”；选择并确认当天才显示“今天”。这符合后续 MIW-37/39 需求；原型截图是选中当天的状态。
- 上轮活动时间压缩时省略了年份，会使跨年/往年活动含义不清，已修复：本年简写，非本年带年份，跨日结束时间带日期。
- 另修复目录刷新后仍指向已移除分类的失效展开状态。
- 实拍还发现原有设备时区与服务端北京时间不一致：纽约设备选12月12日，卡片却显示12月11日。活动列表、详情、报名、反馈、我的活动及签到提示现统一以 UTC+08:00 展示，日历“今天”也使用同一业务日；只转换展示，不更改真实活动时间和筛选接口。新增纽约时区与夏令时专项测试。
- 不修改会籍、支付、权限、报名资格判断，不伪造原型的报名人数。对比图中的人物、等级和活动样例仍是明确标记的本地展示数据；行业完整库和新增测试活动另有真实服务端回读。
- 源目录中存在“美容”“美发”“美容/美发”等语义重叠项。按原始来源保留，后续宜由运营统一字典口径并制定旧 ID 迁移；本轮不擅自合并。
