## 实现与验收

- 机会页原来五个控件放在一条不能收缩的行中，部分宽度会吃掉右侧留白。改为左侧三个状态放入原生横向 scroll-view，右侧筛选和发布固定保留；选中状态自动进入可视区。没有恢复已删除的「地区 + 清除筛选」行。
- 320×568 与 390×844、默认字号、同一真实测试账号和城市：操作区均在屏内；「我的项目」选择、筛选打开/关闭、进入发布编辑页正常。没有发布机会或新增业务记录。本次默认字号三项都能容纳，未以这些截图声称已经实测溢出时的真机滑动手势。
- 头像原先每次应用身份快照都会先设为空，再从缓存恢复，导致原生 image 节点被反复创建。保留相同来源的现有头像，仅在头像删除、退出或来源变化时走既有清理/更新流程。旧包一次切换与强制刷新观察到5次清空；新包每个尺寸3轮切换及强制刷新均为0次清空。两者执行次数不同，不作闪烁频率对照。登出/移除头像的自动化回归通过；手机视觉仍待验。
- 验收站构建生成 WebP 预览，最大宽1280、质量86，仅采用更小结果；原图字节和链接保留。冻结报告原始素材不变。实际体积统计见站点根 image-optimization.json，本轮发布核对另见 site-publication.json。
- 当天页面增加原始需求、目标，以及逐项验收标准/实际结果；此前用户规则、测试数据和性能检查保留，原图不覆盖。无新增权威原型，不放原型占位列。
