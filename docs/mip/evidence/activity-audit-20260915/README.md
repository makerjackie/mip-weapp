## 修复

- 现场入口删除重复说明；四个现场页面左右边距由 48rpx 调整为 24rpx。海报未生成时不显示无用的保存按钮。
- 活动现场页忽略页面隐藏后或后续刷新之前发出的旧请求结果。
- 报名页在等待邀请信息前锁定提交，防止连续点击产生重复请求；不确定请求的重试保留原幂等键。
- 修改活动标题等普通内容不再递增报名表版本；结构实际变化才递增，忽略对象键顺序差异。
- 海报码兼容 PNG/JPEG 和有偏移的二进制视图；扩展名、媒体类型与实际格式一致，保留对象绑定和失败清理。
- Web 活动操作缺少服务端版本时拒绝提交；创建活动的必填校验不再产生未处理 Promise 异常。
- Web DOM 测试并发限制为 2，减少同时启动多个 jsdom/Ant Design 页面造成的 CPU 争用；保留原超时与断言。

## 测试方式

- `cloudfunctions/mip-admin-api/tests/event-lifecycle.integration.test.js`：同一内存数据夹具调用真实 repository/service，依次创建、发布、报名、读取非空名单、签到、重复签到、撤销、结束和查询本人报名。模拟数据库不是实际 MySQL，权限与 SQL 并发另由既有专项测试覆盖。
- `tests/admin-onsite-workbench.test.ts`：真实 DTO parser、Page 方法、延迟响应、海报绘制和失败重试；Canvas、云请求是测试替身。
- `tests/mip-registration-page-recovery.test.ts`：必填、提交锁、请求失败重试及冲突后的草稿恢复。
- `admin-web/src/features/admin-runtime/event-form-dialog.react.test.tsx`：真实 Ant Design 表单的必填失败、内容填写、日期转换及发布版本传递；不是生产浏览器端到端验收。
