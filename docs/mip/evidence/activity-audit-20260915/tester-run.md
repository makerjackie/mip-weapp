## 实际发现并修复

1. **Web 详情侧栏遮挡发布操作窗口**：真实截图和无法触发的按钮确认。统一详情、操作表单和确认窗口层级；在浏览器中保持侧栏打开，两个确认按钮都能响应。
2. **手机日期时间选择器溢出**：390px 屏幕上原页面横向宽度达到 481px，时间列被裁掉。日期与时间改为纵排，面板限制在可视区域内并允许纵向滚动；实际选中日期并确认回填成功。
3. **Web 缺少报名字段配置**：新建/编辑只有隐藏的 schema，运营无法配置问题。增加文字、长文字、单选、勾选和必填配置，自动生成稳定字段标识；对齐服务端 12 字段、字段名称 60 字、选项与字数限制。直接调用真实服务端 schema validator 的合同测试防止前后端漂移。

主审核发现并改正执行稿中的字段标识格式、长度限制和日期面板选择器问题，没有把执行稿的本地测试结果当成验收结论。
