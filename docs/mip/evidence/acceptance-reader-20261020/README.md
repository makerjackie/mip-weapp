# 验收站目录、分享定位与默认画面对照

用户要求：添加目录及对应hash，左侧目录跳转，右侧直接展示详情和画面对照，并适配手机。

- 所有日汇总及兼容单项报告页使用固定侧栏目录；对照组也可定位，当前阅读项高亮。
- 条目、功能分项、对照组、六图标、行业目录和待复测区均可复制带hash的链接；保留原有报告与19号功能锚点，对照排序不改变已有链接。
- 对照图及行业目录直接显示，无需展开；PNG预留固有尺寸，减少图片加载导致的定位偏移。
- 手机/平板顶部固定目录选择器；窄屏对照在局部横向滑动，点击图片仍打开原图，整页不横向溢出。
- 剪贴板拒绝时提供地址栏复制提示；禁用JavaScript时仍有普通目录及直接可见的图片。

本批仅改验收站阅读界面，业务报告结论、截图、原型身份与原提交时间保持。不修改或重新验收小程序/管理后台业务；本批无对应原型，不添加原型占位。

本地真实Chrome检查两天页面各4视口：1440×1000、1280×900、390×844、768×1024，共8组。通过目录/高亮、剪贴板实际读取、带hash重载后定位、图片解码、浏览器返回、局部横滑及整页无溢出；另测复制拒绝和无JavaScript回退。详见[本地结果](local-browser.json)。手机与平板指浏览器视口，未冒充iPhone真机测试。
