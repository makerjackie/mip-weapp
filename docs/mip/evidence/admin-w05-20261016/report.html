3. 修复明细（含“为什么”）

缺陷现象修复
退款入口不认识签到状态已签到活动的已支付订单，非超管仍看到「提交退款」，点了必然被事务拒绝（EVENT_REFUND_CHECKIN_ACTIVE）入口投影改为与退款事务同口径：非超管 + 生效签到 → 不给入口，改为返回 blockedRefundActions 原因；界面显示禁用按钮并给出原因
反馈合同缺失会整页报错反馈响应非空但缺 displayFields 时抛错，整个活动抽屉变错误页降级占位 + 区块提示，不再拖垮整页（“可选请求失败不得让已成功正文变整页错误”）
签到码按钮能力不一致动作投影按 events.write 暴露签到码，实际动作要求 events.checkin.manage → 看得见但会失败投影改为 events.checkin.manage，与动作自身校验一致
签到码刷新不吊销旧码仅 ROTATING 吊销旧码；STATIC 反复下发会同时存在多个有效码同模式重新下发时吊销旧的有效码
全量名单泄漏 userIdrosterAll 返回原始 userId，与 roster 脱敏不一致移除 userId，与单场名单口径一致
