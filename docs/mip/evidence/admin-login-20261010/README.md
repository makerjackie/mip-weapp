**登录码：**新站六位码通过真实 Chrome → 微信开发者工具输入/确认 → 管理云函数 → 新站 BFF → Chrome 自动登录并展示真实概览；旧站六位码也完成真实确认、管理会话和退出。新站 scene token 用真实小程序页面按钮确认，BFF 返回 `AUTHENTICATED`，管理会话和退出通过。没有注入身份。二维码生成接口返回图片与保留命名空间，但未做手机实际扫码。
