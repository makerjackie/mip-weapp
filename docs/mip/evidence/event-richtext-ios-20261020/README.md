# iPhone体验版：生产早会主办方三图空白（2026-10-20）

[图文对照](index.html) · [验证记录](verification.json)。继续更新同一份[对外草稿报告](https://miptest.01mvp.com/reports/event-media-player-free-20261020-v1/)。

生产“**MIP反人性早会10月22日**”正常回读：活动介绍无插图或独立图库，报名须知无插图；**主办方介绍确实保存3张图片**。修改前实际页面的三个img节点均为本地临时路径。普通image可显示和SDK可解码，并不代表rich-text能显示。

微信[rich-text官方说明](https://developers.weixin.qq.com/miniprogram/dev/component/rich-text.html)明确：**img标签仅支持网络图片**。此前把封面/image组件的本地下载缓存与富文本混用，导致iPhone主办方图片空白。本次给富文本使用已有服务端受控签发的HTTPS地址，独立8分钟缓存；只允许HTTPS进img节点，切换标签时重新水合以更新过期签名。云存储保持私有，未新增签发权限、修改业务内容、数据库或云函数；收费规则未变。

生产真实活动原数据验证：3个主办方img节点从3个临时路径变为3个HTTPS地址，3图1200×1600实际解码，开发工具真实富文本画面已见3张照片，标签离开再进入正常。另用测试库正常图文活动验证介绍3、主办方1、须知2、报名页2张图片均使用HTTPS并正常读取。缓存隔离、并发签发、过期、身份切换、离页竞态和标签重建有回归。

Node22.23.1完整verify:all通过：小程序281套/1825项、Web Node330项、Web React34套/253项；生产环境客户端**1.0.3上传成功**。源码cee5eabe；生产包无测试函数引用，保留嵌套TDesign依赖。实际验收工程的482个产物文件与最终上传工程逐字节一致（配置文件不作运行源码比较），主包1,764,355字节。二维码仅保留本机，不发布到验收站。

**体验版仍需人工切换**：微信公众平台→版本管理→开发版本→找到1.0.3→设为体验版。当前工具受公众平台访问限制，未完成或宣称该操作；未提审或全量发布。修复后iPhone真机待用户复核。
