# 小程序 UI 审计修复

日期：2026-09-05。范围：当前工作树的小程序界面；不涉及服务端部署。

## 修复内容

- 机会编辑：必填说明和合作角色在基础区显示；字段错误就地展示，并定位首个缺项。
- 活动反馈：未完成时允许点击保存，显示缺项说明并定位；保存中继续防止重复操作。
- 机会首页：恢复常驻地点入口，区分“不限”与“全国”；次要导航收进“更多”并保持可达；空封面复用正式品牌资源。
- 活动首页：只保留一组近期/结束状态；选择或清除日期范围保留当前活动状态，时间工具单独成行。
- 基础体验：扩大明确偏小的点击区域，辅助文本提升至至少 22rpx，补充输入标签、未读文字、列表加载语义及个人主页空态。
- 组件一致性：TabBar 选中语义与灰色 token、徽章页退出和安全区、设置与现场工作台间距/圆角。
- 分享按钮：绿色和蓝色底色下白字对比度分别为 5.09:1、6.05:1。

活动详情主按钮原有 88rpx 外层命中区；其内部 80rpx 视觉面保留。机会首页胶囊也应根据外层命中区验收，不以内部视觉尺寸判断点击区。
