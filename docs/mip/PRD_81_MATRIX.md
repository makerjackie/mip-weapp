## 判定规则

- `implemented-local` 必须能从页面入口到 module、云函数、`mip_*` 表及测试追踪，不能只是路由或占位文案。
- `external-wait` 不等于未实现；它表示源码链路存在，但最终事实依赖真机、正式 AppID/支付/AI/订阅消息配置、CloudBase 部署或原始设计资产。
- Figma 同尺寸视觉对照、运行时页面状态证据和正式环境验收由 [ACCEPTANCE.md](ACCEPTANCE.md) 统一记录，不在本表伪造通过结果。
