# 对外验收报告站

固定入口：<https://miptest.01mvp.com>，Cloudflare Pages 项目 `miptest`。这里发布已脱敏、可给测试人员和客户查看的验收报告，不承载业务后台。

## 每次任务的交付流程

1. 实际修复并验证后，在 `reports.json` 新增报告；同一需求尚未定稿/外发时更新原草稿。未执行、失败、真机待测必须分别写明，不能因测试绿或上传成功而宣称验收通过。
2. 每份报告记录标题、需求标识、版本、草稿/定稿、创建/更新时间、实际验证时间、首次提交时间、代码提交 SHA 与提交时间、环境、验证结论和未验收项。首页按更新时间倒序，以北京时间日期分组，每天合并为一条验收记录，点击直接进入包含当天全部内容的页面；正文只列主要改动与必要的待复测事项。精确时间、代码SHA等追踪信息保留源数据，不显示在面向客户的正文。
3. `comparisons` 只在界面变化时展示必要的修改前后截图，折叠查看；有当前权威原型原图时加原型列，无原型不放占位列。纯功能/性能优化标记 `uiChange: false`，不强制提供截图。截图仍保留来源、环境、视口、角色/样本差异；不得用旧原型、自制图或功能截图充当原型。
4. 只引用已人工检查、可公开的文件，放入对应的 `docs/mip/evidence/`；不发布二维码、个人资料、账号、密钥、订单编号或原始云端日志。旧报告的原始证据不随新报告覆盖。
5. `node scripts/acceptance-site.mjs build` 生成隔离输出；检查桌面和390px手机页面、图像解码、内部链接及实际内容。`node scripts/acceptance-site.mjs publish` 发布到既有项目，随后核对真实域名所有文件字节和浏览器画面。
6. 用户明确说“定稿/已经发给客户”后，先核对报告完整，再运行 `node scripts/acceptance-site.mjs freeze <id>` 并提交。定稿内容及图片摘要锁定，后续构建拒绝修改。新需求或定稿后反馈，复制为新的 `id` 和递增 `version`，填写 `previousVersion`，生成新版本；保留旧版本 URL 和时间。

`daily-summaries.json` 可编辑当天的简短标题、概述和共同待复测事项；只概括已有证据，不把测试/开发工具结果写成生产或真机验收通过。当天页面直接呈现各项要点及可展开的画面对照，不再作为跳到五篇报告的中间层；原报告URL继续保留。

单项文案可通过 `indexTitle`、`highlights` 与 `pendingSummary` 提炼；它们只概括现有证据，不改写验证结论。当天汇总由报告自动生成至 `/updates/YYYY-MM-DD/`，保留每份报告原始 URL、首次提交时间和冻结规则。

`submittedAt` 是该报告首次发布到验收站的时间，`verifiedAt` 是实际验证时间，`commitAt` 是代码提交时间，三者不得混用。草稿后续反馈只更新 `updatedAt`、结论与证据；首次提交时间不变。冻结后不能改标题、时间、结论、图片或锁文件来绕过约束。

历史站在 `legacy/20260927/` 完整保留，属于历史模拟画面报告，不自动升级为当前真机/功能通过。用户2026-10-20已要求将 `mip-review.01mvp.com` 合并迁入本站：原站36个公开文件完整保存在 `legacy/20261019/`，通过archive.json逐文件摘要检查防止改写。原日期和旧原型身份保留，首页补10月19日入口；在新站全部文件验证后，旧域名通过既有Pages项目跳转到对应存档路径，不删除项目或改DNS。

迁入的旧报告用 `reportDate` 保留原页面日期；创建、提交和本次验证时间记录新站迁移行为，不伪造旧站的精确首次发布时间。`roleIcons`、`prototypePreview` 与 `downloads` 直接引用经过核对的原文件；原报告保持完整字节，旧原型不能冒充当前稿。

旧站切换使用 `node scripts/redirect-mip-review.mjs publish`：先从真实miptest域名回读全部36个原始文件并比对归档SHA，全部匹配后才部署既有mip-review项目的跳转。切换后分别验证旧首页、锚点、SVG及ZIP下载仍到新站对应路径。规则来源：[Cloudflare Pages redirects](https://developers.cloudflare.com/pages/configuration/redirects/)。

迁移后旧mip-review项目只维护跳转；后续新增或更新报告只发布miptest，不再用历史临时脚本覆盖旧项目。
