# mip-community-api

提供公开公告和知识内容读取，以及完成当前协议、手机号、昵称和主分会后的社区安全与活动评论能力。活动评论复用通用 `mip_content_*` 表的 `EVENT` 目标，不接受客户端提交的作者、活动状态或管理范围。

MIP 用户侧社区安全服务。仅接受 AppID 绑定的 `profileRef`，负责屏蔽、解除屏蔽、个人屏蔽列表和举报事实；不发送站内或微信通知。

所有身份、目标用户和归属都由可信 CloudBase 上下文及 `mip_*` MySQL 表重建。客户端不能提交用户 ID、OpenID 或举报状态。

活动评论列表只读取当前可见活动；`CANCELLED`、`ENDED` 必须存在服务端 `published_at` 事实。发布和编辑执行微信内容安全检查，编辑窗口为 30 分钟；删除为软删除。发布、编辑、删除和举报均使用稳定幂等键，并在事务内重新检查当前身份和活动事实；编辑、删除、举报同时检查作者和版本，列表与举报应用双向屏蔽过滤。
